# 🍕 vrtelolleva - Plataforma de Delivery

Aplicación web completa para gestión de pedidos de comida a domicilio, conectando clientes, negocios y repartidores.

## 🚀 Características Principales

### Para Clientes
- 🔍 Búsqueda y filtrado avanzado de restaurantes
- 🛒 Carrito de compras inteligente
- 📍 Selección de ubicación para entrega
- 📱 Seguimiento de pedidos en tiempo real
- ⭐ Sistema de calificaciones para negocios y repartidores
- 🔔 Notificaciones en tiempo real
- 📋 Historial completo de pedidos

### Para Negocios
- 📦 Gestión de pedidos activos
- 🍔 Administración completa de menú/productos
- ⏰ Control de horarios (abierto/cerrado)
- 👥 Visualización de repartidores disponibles
- 📊 Historial de pedidos y estadísticas
- ✏️ Edición de perfil del negocio

### Para Repartidores
- 🚴 Toggle online/offline
- 📦 Lista de pedidos disponibles para recoger
- 🗺️ Gestión de entregas activas
- 💰 Seguimiento de ganancias
- 📍 Información de ubicaciones de entrega

### Para Administradores
- 👥 Gestión completa de usuarios
- 🏪 Aprobación/rechazo de negocios
- 📊 Estadísticas globales de la plataforma
- 📋 Visualización de todos los pedidos
- 💵 Control de ingresos totales

## 🎨 Diseño

- Sistema de colores vibrante con tema naranja-rojo para delivery
- Modo claro y oscuro completamente funcional
- Animaciones suaves y transiciones
- Diseño responsive para todos los dispositivos
- Componentes UI con shadcn/ui

## 🎯 Flujo de Pedido

1. **Cliente** busca restaurantes y agrega productos al carrito
2. **Cliente** selecciona ubicación y método de pago, envía pedido
3. **Negocio** recibe notificación y acepta/rechaza el pedido
4. **Negocio** prepara el pedido y lo marca como listo
5. **Repartidor** ve el pedido disponible y lo acepta
6. **Repartidor** recoge y entrega el pedido
7. **Cliente** recibe el pedido y puede calificar el servicio
